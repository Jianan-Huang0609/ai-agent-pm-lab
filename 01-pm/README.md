# 🎯 产品经理视角

> 如何把用户痛点转化为 AI Feature

## 核心命题

- 用户真正的痛点是什么？不是他们说的，是他们做的
- 哪些痛点是 AI 可以解决的？哪些不适合？
- Feature 优先级：ROI（用户价值 × 实现可行性）
- 交互边界：Agent 做多少，用户看多少
- 放权路线：MVP 硬约束 → 参数配置 → 用户自定义

## 思考框架

1. 用户故事 → 痛点拆解 → 行为数据验证
2. 竞品/替代方案分析 → 差异化定位
3. AI Feasibility 评估（准确率要求、延迟容忍、错误成本）
4. 交互模式设计（Pipeline vs Agent、Gate 节点设计）
5. 放权节奏（哪些先写死、哪些留给用户）
