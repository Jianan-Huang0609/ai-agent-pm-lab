# AI Agent PM Lab 🧪

> 从产品经理到架构师，从交付到商业拓展——关于 AI Agent 产品的全角色思考与进化日志。

## 这是什么

一个个人精进项目。记录我在 AI Agent 产品领域，跨越四个角色的思考、设计、决策和复盘：

| 角色 | 目录 | 核心命题 |
|------|------|---------|
| 🎯 **产品经理** | `01-pm/` | 如何把用户痛点转化为 AI Feature |
| 🏗️ **架构师** | `02-architect/` | 如何把 Feature 转化为真实的 AI 架构（Multi-Agent / Prompt-Level / Workflow Automation） |
| 📊 **产品负责人** | `03-po/` | 如何为 Stakeholder 长期监管项目，定义和拔高关键指标 |
| 💼 **商业拓展** | `04-bd/` | 如何做 BD、创业、完整拓展业务 |
| 🎤 **面试备战** | `05-interview-prep/` | Agent 开发面试题与深度解析 |
| 📝 **模板** | `06-templates/` | 可复用的思考/决策/设计模板 |

## 为什么建这个项目

Agent 产品开发不是单纯的工程问题，它要求你同时理解：

- **用户要什么**（PM 视角）
- **技术上怎么实现**（Architect 视角）
- **交付后怎么衡量好坏**（PO 视角）
- **怎么让更多人用起来**（BD 视角）

四个视角之间频繁切换和深度思考，才能做出真正好的 Agent 产品。这个仓库就是这场进化旅程的日志。

## 使用方式

- **Claude Code 模式**：开仓库后自动加载 `CLAUDE.md`，Claude 了解全貌，配合你深入讨论任一方向
- **手动记录**：每次有新的思考、决策或复盘，写入对应目录，打上日期
- **面试备战**：`05-interview-prep/` 中的题目持续新增和迭代答案
