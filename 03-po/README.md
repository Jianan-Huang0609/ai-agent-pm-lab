# 📊 产品负责人视角

> 如何为 Stakeholder 长期监管项目，定义和拔高关键指标

## 核心命题

- 关键指标体系：模型指标（准确率/召回率） + 业务指标（用户满意度/效率提升）
- 无用户反馈时如何抽检：分层抽样、边界 Case 自动化测试集
- Badcase 定位：快速找到是哪个 Agent 环节出错
- SFT 决策：什么时候 Prompt 调不动了该上 SFT
- Prompt 调优中的「修好一类坏了另一类」如何解决
- 效果评估体系：online vs offline、A/B 测试、回归测试

## 指标体系框架

```
用户端指标：
  ├── 任务完成率
  ├── 平均交互轮数
  ├── 用户修正率（Gate 处推翻 Agent 判断的频率）
  └── 满意度（显式评分 / 隐式行为）

模型端指标：
  ├── 抓取准确率
  ├── 比对召回率
  ├── 自动修正准确率（Agent 改对的比例）
  ├── 假阳性率（标记需确认但实际没错）
  └── 端到端成功率
```
